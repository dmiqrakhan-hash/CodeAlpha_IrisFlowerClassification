# CodeAlpha Iris Flower Classification

CodeAlpha Data Science Internship — Task 1

## Project Overview
This project uses machine learning to classify Iris flowers into three species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Dataset
The Iris dataset contains flower measurements:
- Sepal length
- Sepal width
- Petal length
- Petal width

## Methodology
1. Load the Iris dataset.
2. Split the data into training and testing sets.
3. Train a Decision Tree classifier.
4. Evaluate the model using accuracy and a classification report.

## Results
Model accuracy: 93.33%

The confusion matrix shows that 28 out of 30 test samples were correctly classified.

## Tools Used
- Python
- Scikit-learn
- Machine Learning

## How to Run
Install the required library:

pip install scikit-learn

Run the program:

python iris_classification.py
